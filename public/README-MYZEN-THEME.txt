MYZEN MONEY - Unified Theme Update

This package contains the updated public website files only.

INSTALL:
1. Back up your current project folder:
   C:\xampp\htdocs\myzen-money-js\public
2. Extract this ZIP.
3. Copy the included "public" folder into:
   C:\xampp\htdocs\myzen-money-js\
4. Allow Windows to replace the existing public files.
5. Open the website and press Ctrl+Shift+R.

THEME:
- Brand accent: MYZEN Blue (#155eef)
- Shared stylesheet: public/css/theme.css
- Light/Dark theme is read from localStorage keys:
  myzen_settings.theme and myzen_theme

IMPORTANT:
- This ZIP intentionally contains only public website files.
- It does not contain backend credentials, .env, serviceAccountKey.json,
  node_modules, or Firebase deployment configuration.
- No backend or Firebase logic was intentionally changed.
